# Renaming the Assistant

NanoClaw uses a configurable assistant name. By default, the assistant is named **Andy**. You can rename it without modifying any code.

## Quick Rename

### Option 1: Temporary (for one session)

```bash
ASSISTANT_NAME=Jarvis npm start
```

### Option 2: Persistent (for all sessions)

Edit `.env` and change:

```bash
ASSISTANT_NAME=Jarvis
```

Then rebuild and restart:

```bash
npm run build
npm start
```

## Update Memory Files

The assistant's name appears in group memory files (CLAUDE.md). Update them to match the new name:

```bash
# Replace @Andy with @Jarvis in all group memory files
sed -i '' 's/@Andy/@Jarvis/g' groups/*/CLAUDE.md

# Also update any prose references
sed -i '' 's/Andy/Jarvis/g' groups/*/CLAUDE.md
```

## Verify the Change

Run tests to confirm everything works with the new name:

```bash
ASSISTANT_NAME=Jarvis npm test
```

All tests should pass with any assistant name.

## Channels and Triggers

The assistant name is used for:

1. **WhatsApp trigger pattern**: Messages must start with `@{ASSISTANT_NAME}` (e.g., `@Jarvis hello`)
2. **Telegram command**: `/set_alias` sets the bot's display name in Telegram
3. **Voice channel**: The agent introduces itself by the configured name
4. **Memory context**: CLAUDE.md files reference `@{ASSISTANT_NAME}` for trigger patterns

## Example

Rename from Andy → Jarvis:

```bash
# 1. Update .env
echo "ASSISTANT_NAME=Jarvis" > .env

# 2. Update group memory
sed -i '' 's/@Andy/@Jarvis/g' groups/main/CLAUDE.md

# 3. Verify
npm test

# 4. Build and run
npm run build
npm start
```

Now WhatsApp messages must start with `@Jarvis` to trigger the agent.

## Troubleshooting

### Tests fail with the new name

This shouldn't happen. If it does, check:
- `.env.example` is properly documented
- Test files use `ASSISTANT_NAME` from config, not hardcoded strings
- Group memory files reference the correct trigger pattern

### Messages not triggering in WhatsApp

Make sure:
- `.env` has the updated `ASSISTANT_NAME`
- Group memory file (`groups/main/CLAUDE.md`) has the correct trigger pattern (e.g., `@Jarvis`)
- Container is rebuilt: `npm run build`
- Service is restarted: `npm start`

### Commands still use old name in Telegram

Telegram bots require re-initialization:
1. Update `.env` with new `ASSISTANT_NAME`
2. Restart the service
3. Use `/mybots` in BotFather to update the bot's display name if desired

## How It Works

The assistant name is stored in `.env` as `ASSISTANT_NAME` and loaded at startup:
- Used to build the trigger pattern regex (e.g., `^@Jarvis\b`)
- Passed through to the agent container and group memory context
- Tests dynamically reference it, so renaming works without test code changes

**No code changes required—just update `.env` and memory files.**
